# Assets / Media

This site prefers **short looping product demos** (WebM/MP4) instead of animated GIFs.

Why:
- Much smaller for the same quality (better Core Web Vitals).
- Video can be hardware-decoded on most devices.
- Better control over loading behavior (poster, preload metadata).

## How these are produced

Every demo clip, hero/CTA loop, poster, and screenshot on this site is
generated by the marketing-capture web lane in the code repo
(`web_referee/frontend/marketing-capture`, see its README's "Web lane"
section) from the live app. Never hand-make a site media asset again — add or
change a `<video>`/`<img>` reference here, write the matching scene file in
the rig, and run its capture command from the code repo.

Keep the creative guidance in mind when writing a scene: short, seamless
loops; avoid tiny UI text; prefer showing a single "aha" moment.

## Demo posters (`images/features/*.jpg`)

Posters are rendered by the web lane itself, from the clip's own frames: each
scene declares `posterBeat` / `posterOffset` in its meta to pick its money
moment (see the rig README's scene contract). Never hand-make a poster; if a
poster shows the wrong moment, adjust the scene's `posterBeat` and re-run the
capture.
