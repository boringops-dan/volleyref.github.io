# How many sets are in a volleyball match?

**Short Answer:** International, Olympic and college matches are best of 5 sets: the first team to win 3 sets wins. High school matches are best of 5 unless the state adopts best of 3, and many youth club and pool-play matches are best of 3, as is beach volleyball. Indoor sets go to 25 points and the deciding set to 15.

## Full Explanation

Per FIVB Rule 6.3.1, the match is won by the team that wins three sets, so it is played as the best of 5 sets. Each set except the deciding 5th set is played to 25 points with a minimum 2-point lead (FIVB Rule 6.2). The deciding set 5 is played to 15 points with a minimum 2-point lead (FIVB Rule 6.3.2). There is no point cap under FIVB, USAV, NCAA or NFHS rules. Under NFHS rules, varsity matches are best of 5, with sets 1 to 4 played to 25 points and the deciding fifth set to 15, each won by 2 points with no cap. State associations may adopt best-of-3 matches, in which all sets are played to 25. NCAA uses best-of-5 with sets to 25 (15 in set 5), no cap. USAV matches may be best of 3 or best of 5; in a best-of-3 match the first team to win 2 sets wins and the deciding set 3 is played to 15 points. Youth club tournaments commonly use best of 3 in pool play. A 5th set (or 3rd set in best of 3) is played only when the sets are tied. Beach volleyball matches are best of 3, with sets 1 and 2 played to 21 points and the deciding set to 15, each won by 2 points (FIVB Beach Volleyball Rules). The format used is determined by the governing body or tournament director.
