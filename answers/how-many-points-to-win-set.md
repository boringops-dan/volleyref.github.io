# How many points does it take to win a set in volleyball?

**Short Answer:** Indoor volleyball sets are played to 25 points and the deciding set to 15, each won by a 2-point lead with no cap. Beach volleyball sets go to 21 (deciding set 15), and snow volleyball sets go to 15.

## Full Explanation

Per FIVB Rule 6.2, a set (other than the deciding set) is won by the team that first scores 25 points with a minimum 2-point advantage. If the score reaches 24-24, play continues until one team leads by 2 (no cap under FIVB, USAV, NCAA or NFHS). The deciding set (set 5 in a best-of-5 match) is won at 15 points with a 2-point lead (FIVB Rule 6.3.2). NFHS Rule 1-4 sets the first four sets at 25 points and the deciding fifth set at 15 points, each won by at least 2 points with no cap; in a best-of-3 match adopted by a state association, all three sets are played to 25. In a USAV best-of-3 match the deciding third set is played to 15. Some state associations allow capped sets (for example 27 and 17) only in sub-varsity play. Beach volleyball, per the FIVB Beach Volleyball Rules, is best-of-3 with sets 1 and 2 played to 21 and the deciding set to 15, each won by 2 with no cap. Snow volleyball plays every set, including the decider, to 15 points with a 2-point lead.
