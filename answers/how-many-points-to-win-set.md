# How many points does it take to win a set in volleyball?

**Short Answer:** Sets 1-4 require 25 points with a 2-point lead. The deciding set (set 5) requires 15 points with a 2-point lead. FIVB, USAV, NFHS and NCAA rules have no point cap.

## Full Explanation

Per FIVB Rule 6.2, a set (other than the deciding set) is won by the team that first scores 25 points with a minimum 2-point advantage. If the score reaches 24-24, play continues until one team leads by 2 (no cap under FIVB, USAV, NCAA or NFHS). NFHS Rule 1-4 sets the first four sets at 25 points and the deciding fifth set at 15 points, each won by at least 2 points with no cap. The deciding set (set 5) is won at 15 points with a 2-point lead (FIVB Rule 6.3.2). Some state associations allow capped sets (for example 27 and 17) only in sub-varsity play.

**Rulesets:** FIVB/USAV/NFHS/NCAA
**Rule Reference:** FIVB Rule 6.2; FIVB Rule 6.3.2; USAV Rule 6.2; NFHS Rule 1-4; NCAA Rule 8.2
